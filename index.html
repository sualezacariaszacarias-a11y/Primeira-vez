Aprenda FlexBox

Flexbox é um modelo de layout CSS que permite criar layouts flexíveis e responsivos.

display Flex

Esta propriedade transforma o elemento em um flex container, podendo ser do tipo 'inline' ou 'block',
dependendo dos valores. Ela faz com que todos os elementos-filhos diretos passem a ser tratados no contexto do Flexbox

Justify content

justify-content: Controla o alinhamento dos itens ao longo do eixo principal.

Align Items

align-items: Alinha os itens ao longo do eixo transversal.

Flex Wrap

flex-wrap: Permite que os itens quebrem a linha e se ajustem em múltiplas linhas, se necessário

Layout Responsivo

Ele e responsavel na criacao de layouts que se adaptam a diferentes tamanhos de tela,tornando o design mais fluido.

Alinhamento Perfeito

permite um alinhamento dos elementos de forma horizontal quanto na vertical

Distribuição de espaco

permite a distribuição e espacamento dos conteudos, sem usar floats ou posicionamento absoluto.
